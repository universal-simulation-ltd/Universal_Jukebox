# Example library sleeve photos

The photos behind the example library's sleeves (`src/lib/exampleCovers.ts`).
Every one is **CC0 1.0** (public domain dedication): free to use, change and
ship, with no attribution required. The photographers are named here anyway.
Each was cropped square and resized to 720 × 720. The album name is set over
it at run time (`drawSleeve` in `src/lib/exampleLibrary.ts`).
